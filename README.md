# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:
To develop the Hospital management System using Star UML tool.

# SRS (Procedure):
```
Start the system.

User logs in (admin, doctor, or patient).

Admin manages doctor and patient records.

Patient registers and provides personal details.

Patient books an appointment with a doctor.

Doctor views patient details and updates diagnosis or prescriptions.

System stores and updates all medical records.

Admin can generate reports for patients, doctors, and appointments.

User logs out.

End.
```
